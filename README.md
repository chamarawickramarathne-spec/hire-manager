# 💎 Hire Artist Manager (Lens Manager)
**The Ultimate Power Center for Photography Platform Administrators.**

Hire Artist Manager is a premium, high-performance administration portal designed to manage a vast ecosystem of photographers and visual artists. It serves as the central brain of the platform, allowing administrators to oversee user growth, monetize through smart subscription plans, and maintain complete control over system permissions.

## 🇱🇰 සිංහලෙන් (Sinhala)

### Hire Artist Manager යනු කුමක්ද?
**Hire Artist Manager** යනු විශාල ඡායාරූප ශිල්පීන් සහ කලාකරුවන් පිරිසක් එක්ව සිටින වේදිකාවක් ඉතාමත් කාර්යක්ෂමව පාලනය කිරීම සඳහා නිර්මාණය කරන ලද උසස් මට්ටමේ පරිපාලන පද්ධතියකි (Admin Portal). මෙය මුළු පද්ධතියේම "මධ්‍යම මොළය" ලෙස ක්‍රියා කරන අතර, පරිපාලකවරුන්ට පරිශීලකයින්ගේ වර්ධනය, දායකත්ව පැකේජ (Subscriptions) සහ පද්ධතියේ ආරක්ෂාව (Access Levels) ඉතා පහසුවෙන් හැසිරවීමට ඉඩ ලබා දෙයි.

### මෙමඟින් ඔබට ලැබෙන ප්‍රයෝජන (How it helps you)
1.  **මධ්‍යගත ව්‍යාපාරික පාලනය (Centralized Control):** විවිධ මෙවලම් අතර කාලය නාස්ති නොකර, සියලුම ඡායාරූප ශිල්පීන්ගේ තොරතුරු සහ ව්‍යාපාරයේ ප්‍රගතිය එකම තැනක සිට විමසා බැලිය හැක.
2.  **ආදායම් සහ පැකේජ කළමනාකරණය (Monetization):** Free, Pro හෝ Business වැනි විවිධ ගෙවීම් පැකේජ සකස් කිරීම සහ එක් එක් පැකේජයට හිමිවන පහසුකම් (Storage limits, Client limits) තීරණය කිරීමේ හැකියාව.
3.  **උසස් දත්ත ආරක්ෂාව (Enhanced Security):** පද්ධතියට ප්‍රවේශ වන විවිධ පුද්ගලයන්ට ලබා දෙන අවසරයන් (Permissions) තනි තනිව පාලනය කිරීමේ හැකියාව. එමගින් ඔබේ ව්‍යාපාරික දත්තවල රහස්‍යභාවය සුරැකේ.
4.  **ස්වයංක්‍රීය පද්ධති නඩත්තුව (Automated Maintenance):** දායකත්ව කාලය අවසන් වීම් (Expiries) සහ අනෙකුත් පද්ධති ක්‍රියාකාරකම් ස්වයංක්‍රීයව (Cron Jobs මගින්) හැසිරවීම නිසා පරිපාලන කටයුතු පහසු වේ.
5.  **දත්ත විශ්ලේෂණය (Analytics):** ව්‍යාපාරය පිළිබඳ නිවැරදි තීරණ ගැනීමට උපකාරී වන සජීවී ප්‍රස්ථාර සහ වාර්තා මගින් පරිශීලකයින්ගේ ක්‍රියාකාරීත්වය සහ ජනප්‍රිය පැකේජ පිළිබඳව නිරන්තර අවධානය යොමු කළ හැක.

### ප්‍රධාන විශේෂාංග (Key Features)

## 🇺🇸 English

### What is Hire Artist Manager?
**Hire Artist Manager** is a professional administrative platform built to oversee a network of photographers and artists. It empowers administrators with tools to manage user accounts, pricing tiers, and system permissions seamlessly, ensuring the platform runs smoothly and profitably.

### How it helps the user
1.  **Business Efficiency:** Streamlines administrative tasks by providing all management tools in one intuitive, high-performance interface.
2.  **Scalable Growth:** Allows the platform to scale easily by adding unlimited photographers and defining custom resource limits per plan.
3.  **Revenue Control:** Full control over subscription modeling, allowing you to adjust pricing and feature availability based on market demand.
4.  **Automated Maintenance:** System handles background tasks like trial expiries and subscription updates automatically via Cron Jobs, reducing manual overhead.
5.  **Actionable Insights:** Built-in analytics provide a bird's-eye view of platform metrics, helping you identify growth opportunities and user trends.

### Key Features
*   **Analytics Dashboard:** Real-time data visualization of platform metrics and active user stats.
*   **Photographer Management:** Comprehensive tools to onboard, monitor, and manage photographer profiles and storage.
*   **Subscription Management:** Define and adjust subscription plans, pricing, and feature limits (e.g., storage GB, max clients).
*   **Granular Access Control:** Define exactly what different administrative roles can see and do within the portal.

## 🛠 Technology Stack
*   **Frontend:** React.js, TypeScript, Vite, CSS3 (Custom Design System)
*   **Animations:** Framer Motion
*   **Charts:** Recharts
*   **Backend:** PHP (REST API)
*   **Database:** MySQL
*   **Icons:** Lucide React

## 🚀 Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Run Development Server:**
    ```bash
    npm run dev
    ```
3.  **Setup Database:**
    Configure your MySQL settings and run `init_db.php` (or `init_db_v2.php`) via your local server environment.
