# Lens Manager - Admin Portal

Lens Manager is a comprehensive administrative dashboard designed for managing a platform of photographers and artists. It provides a centralized hub for administrators to control user access, subscriptions, and system configurations.

---

## 🇱🇰 සිංහලෙන් (Sinhala)

### Lens Manager යනු කුමක්ද?
**Lens Manager** යනු ඡායාරූප ශිල්පීන් සහ කලාකරුවන් කළමනාකරණය කිරීම සඳහා නිර්මාණය කරන ලද මධ්‍යම පරිපාලක වේදිකාවකි (Admin Portal). මින් පරිපාලකවරුන්ට පරිශීලක ලියාපදිංචිය, දායකත්ව සැලසුම් (subscription plans) සහ ප්‍රවේශ මට්ටම් (access levels) කාර්යක්ෂමව පාලනය කළ හැක.

### ප්‍රධාන විශේෂාංග (Key Features)
*   **Dashboard:** මුළු වේදිකාවේම සාරාංශයක් සහ වර්තමාන තත්ත්වය එකවර බැලීමේ හැකියාව.
*   **Photographer Management:** ඡායාරූප ශිල්පීන්ගේ විස්තර ඇතුළත් කිරීම, යාවත්කාලීන කිරීම සහ ඔවුන්ගේ ගිණුම් කළමනාකරණය.
*   **Subscription Control:** විවිධ පැකේජ (Free, Pro, Business) සහ ඒවායේ මිල ගණන් පාලනය කිරීම.
*   **Access Level Management:** එක් එක් පරිශීලකයාට ලබා දෙන කාර්යයන් සහ අවසරයන් (permissions) තීරණය කිරීම.

### මෙමඟින් ඔබට ලැබෙන ප්‍රයෝජන (How it helps you)

3.  **දත්ත ආරක්ෂාව:** පරිපාලකවරුන්ට පමණක් ප්‍රවේශ විය හැකි පරිදි කලාකරුවන්ගේ සහ ගෙවීම්වල දත්ත සුරක්ෂිතව තබා ගනී.

## 🇺🇸 English

### What is Lens Manager?
**Lens Manager** is a professional administrative platform built to oversee a network of photographers and artists. It empowers administrators with tools to manage user accounts, pricing tiers, and system permissions seamlessly.

### Key Features
*   **Analytics Dashboard:** Get a bird's-eye view of platform metrics and active users.
*   **Photographer Management:** Comprehensive tools to onboard, monitor, and manage photographer profiles.
*   **Subscription Management:** Define and adjust subscription plans, pricing, and feature limits.
*   **Granular Access Control:** Define exactly what different user roles can see and do within the platform.

### How it helps the user
1.  **Efficiency:** Streamlines administrative tasks by providing all management tools in one intuitive interface.
2.  **Scalability:** Allows the platform to grow by adding unlimited artists and defining custom plans.
3.  **Security:** Ensures sensitive data is protected via secure admin authentication and role-based access.

## 🛠 Technology Stack
*   **Frontend:** React.js, TypeScript, Vite, CSS3 (Custom Design System)
*   **Backend:** PHP (REST API)
*   **Database:** MySQL
*   **Icons:** Lucide React

## 🚀 Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Run Development Server:**
    ```bash
    npm run dev
    ```
3.  **Setup Database:**
    Configure your MySQL settings and run `init_db.php` via your local server (e.g., XAMPP).
